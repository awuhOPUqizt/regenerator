# django-docker

Menyiapkan aplikasi Django agar bisa dijalankan di dalam kontainer, lalu proses publikasinya diotomatiskan lewat pipeline CI.

## Panduan

Langkah lengkapnya ditulis di halaman catatan terpisah yang ditautkan dari repositori ini. Isinya mencakup penyusunan berkas kontainer, penyambungan basis data, hingga penanganan berkas statis.
